# Histórias de base

Espaço reservado à autoria narrativa em português brasileiro. Crie arquivos Markdown livremente nesta pasta: prólogo, histórias de entrada, histórias paralelas, personagens, localidades e finais. Não é necessário escrever JSON ou código.

A premissa inicial está em [premissa.md](premissa.md). Ela registra apenas a base informada pelo autor; não substitui o roteiro que será escrito aqui.

Sugestão opcional para cada história: título, contexto, personagens, acontecimentos, escolhas e consequências. Não há formato obrigatório nesta fase.
